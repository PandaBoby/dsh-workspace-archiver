# Code of conduct

This project follows the spirit of the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful and constructive. Harassment, discrimination, personal attacks,
doxxing, deliberate disruption, and publishing another person's private data or
session content are not acceptable.

## Scope

This applies in project spaces (issues, pull requests, discussions, reviews, and
chat) and when representing the project in public.

## Reporting and enforcement

Report concerns privately to the maintainers through the repository's private
advisory channel when available, or ask a maintainer for a private channel before
sharing details. Do not include passwords, tokens, session logs, workspace paths,
or personal data in a public report.

Maintainers will review reports in good faith, limit access to the people needed
to handle them, and may warn, remove content, or temporarily or permanently
exclude participants. Retaliation against a reporter is itself a violation.
